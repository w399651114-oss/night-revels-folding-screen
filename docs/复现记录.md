## GitHub 托管 Linux 复建

固定版本的 ubuntu-24.04 运行器从仓库检出 [afcb4bc](https://github.com/w399651114-oss/night-revels-folding-screen/tree/afcb4bc1c2d4522dea3ebb613490b3070e32cece)。首次运行遇到下载站对托管 IP 返回 HTTP 403，工作流随后增加发行镜像回退，每次均按官方 Linux x64 压缩包的固定 SHA-256 校验。复跑成功打开两份发布工程，从空场景生成两份新工程，完成逐帧射线、847 件对象的位置对照和四张抽样渲染。[完整复建记录](https://github.com/w399651114-oss/night-revels-folding-screen/actions/runs/44495884356) · [发布资源基础校验](https://github.com/w399651114-oss/night-revels-folding-screen/actions/runs/44495717106)

跨平台校验比较对象分类、网格面数、尺度、材料、持物联动与空间行为。轮廓边缘的浮点相交可有差异，每帧每个目标允许最多三个射线样点的计数差。macOS arm64 复建额外要求几何指纹一致。
